# The Krill TV — downloads

The desktop app that turns a Windows PC into a television: a ten-foot interface,
a built-in player that finds a working server, and your phone as the remote.

## Download

**[Krill TV.exe](https://github.com/BannedVariable/the-krill-downloads/releases/latest/download/Krill.TV.exe)** — portable, no installer.

Double-click to run. Windows SmartScreen may say the app is unrecognized because
the build is not code-signed: choose **More info → Run anyway**.

The app is self-contained; it does not need the website repository, Node or Bun.
